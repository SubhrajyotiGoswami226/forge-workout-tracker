# Forge — Workout Tracker

Your exact 6-day Push-Pull-Leg split:

- Monday — Pull Day 1
- Tuesday — Leg Day 1
- Wednesday — Push Day 1
- Thursday — Pull Day 2
- Friday — Leg Day 2
- Saturday — Push Day 2
- Sunday — Rest

Every exercise has the programmed sets × reps as its default. The configuration screen pre-fills those values, so you do not need to enter them unless you want to change them for that session.

Session history is stored in browser localStorage.

Run:
```bash
npm install
npm run dev
```
